# Spark

Готовые версии менеджера загрузок Spark. Установленный Spark обновляется отсюда сам.

- Windows: `SparkDownloader-win-Setup.exe`
- macOS (Apple Silicon): `SparkDownloader-osx-arm64-Portable.zip`
- macOS (Intel): `SparkDownloader-osx-x64-Portable.zip`

Скачайте файл из последнего выпуска в разделе Releases.
